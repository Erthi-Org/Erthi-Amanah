# Privacy Policy — Erthi Amanah

## Summary

**Erthi Amanah does not collect, store, or transmit your personal data to any server operated by Erthi or any third party.**

All personal information entered into the application — wills, financial obligations, debts, beneficiary contacts, documents — is stored exclusively on your device.

## Data Storage

| Data type | Where stored |
|---|---|
| Will text, audio, video | Device only (app-private storage) |
| Financial records, debts | Device only (encrypted Room database) |
| Beneficiary contacts | Device only (encrypted Room database) |
| Documents | Device only (encrypted file storage) |
| PIN hash | Device only (encrypted preferences) |
| App preferences | Device only (DataStore) |
| Cloud backup | Your personal cloud account (optional, encrypted before upload) |

## What Erthi Does NOT Do

- Does not operate servers that receive your vault data
- Does not include advertising SDKs
- Does not collect usage analytics or crash reports
- Does not require account registration
- Does not share data with third parties
- Does not upload anything without your explicit action

## Cloud Backup

Cloud backup is fully optional. If you enable it:

- The backup file is **encrypted on-device** before upload
- It is uploaded to **your own account** (Google Drive, OneDrive, Dropbox, or a file you choose)
- Erthi has no access to your cloud storage
- The encryption key never leaves your device in plaintext

## Permissions

Permissions are requested only when you use a feature that requires them. The app functions without location, camera, or microphone if you choose not to use those features.
