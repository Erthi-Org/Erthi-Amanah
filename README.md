# إرثي أمانة | Erthi Amanah

مشروع Android خيري مجاني من إرثي لإدارة المعلومات الشخصية التي يختار المستخدم حفظها للطوارئ أو لإتاحتها لأشخاص يثق بهم.

## نطاق النسخة الأولى

- واجهة عربية RTL وخزنة محلية مشفّرة تعمل دون اتصال.
- يمكن للمستخدم تصدير نسخة احتياطية مشفّرة واختيار مكان حفظها في حسابه السحابي الشخصي.
- تظل بيانات الخزنة على الهاتف ما لم يختر المستخدم تصديرها. لا تستضيف إرثي بيانات الخزنة.
- تُختبر الاستعادة والحذف والتحكم في الوصول قبل اعتبار الخزنة جاهزة.

## حالة المشروع

هذا هو تأسيس المستودع. تطبيق Android وميزات الخزنة والنسخ الاحتياطي قيد التطوير.
تُراجع التغييرات في فروع مستقلة وطلبات سحب، وتُوثق نتائج الاختبارات قبل الإصدار.
